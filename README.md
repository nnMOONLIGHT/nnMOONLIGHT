StyleAI — проект на стыке AI и системы тестирования
ДЛЯ ЗАЩИТЫ ТЕКСТ И ЧТОБЫ НЕ ЗАБЫТЬ

Краткое описание
StyleAI — веб‑приложение, которое объединяет систему онлайн‑тестирования и нейросетевой анализ фотографий. Пользователь проходит тест на определение своего визуального стиля, а затем может загрузить фото, чтобы AI подтвердил или оспорил результат. Бэкенд на C# (ASP.NET Core + EF Core + SQLite + JWT) хранит тесты, ответы и историю анализов, а Python‑микросервис на FastAPI обслуживает обученную с нуля нейросеть‑классификатор.

Идея проекта
Обычно тесты на «какой ты стиль» построены на самооценке: человек сам выбирает ответы и получает предсказуемый результат. Проблема в том, что самооценка субъективна — пользователь может ошибаться в том, как он выглядит со стороны.

StyleAI решает это двумя сигналами:

Тест — что человек думает о себе (ответы на вопросы про одежду, хобби, цвет).

AI‑анализ фото — что видит алгоритм (низкоуровневая визуальная статистика снимка).

Если оба сигнала совпали — стиль подтверждён с высокой уверенностью. Если разошлись — система показывает оба вердикта и рекомендации для каждого. Это превращает обычный тест в инструмент самонаблюдения, а не в развлечение.

Суть проекта
Что делает пользователь
Регистрируется — получает JWT и роль (ученик или менеджер).

Проходит тест «Какой у тебя стиль?» — отвечает на 8–10 вопросов.

Получает результат — например, «Стрит‑стайл, 70%».

Загружает фото (опционально) — система отправляет его в AI‑сервис.

Видит карточку согласованности:

AI подтвердил: Стрит‑стайл (89%) — если совпало.

Тест: Стрит‑стайл, AI: Гранж — если разошлось.

Получает рекомендации — палитра, одежда, хобби, направления обучения.

Что делает менеджер
Создаёт и редактирует тесты, вопросы, варианты ответов.

Смотрит статистику: какие стили популярны, сколько подтверждений AI, где чаще всего расходятся тест и фото.

Управляет каталогом стилей.

Что именно делает нейросеть
Это не готовая модель из интернета, а полностью самописная система:

Датасет (dataset.py) — генерируется процедурно, потому что лицензионных фото нет. 8 стилей × 450 картинок = 3600 изображений, у каждого — свои цветовые и текстурные характеристики.

Признаки (features.py) — 15 чисел на картинку: средние RGB/HSV, контраст, насыщенность, «цветность», плотность краёв (Sobel), доля тёмных/светлых пикселей, симметрия. Никаких предобученных backbone.

Модель (model.py) — MLP (15 → 32 → 16 → 8) на чистом numpy: forward, backward, Adam написаны вручную.

Обучение (train.py) — 400 эпох, точность на валидации ~100% (данные синтетические, поэтому легко).

Инференс — Python‑функция predict() внутри FastAPI, а также зеркальная JS‑версия для мгновенного превью в браузере.

Важно: модель классифицирует визуальный стиль фото (минимализм, стрит, ретро, романтика, гранж, авангард, классика, поп‑арт), а не «типаж человека». Это честная формулировка того, что она умеет.

Технологии по слоям:

Frontend — загрузка фото, прохождение теста, отрисовка карточки согласованности.

Backend — авторизация, тесты, хранение анализов, бизнес‑логика.

ML‑сервис — Python, FastAPI, numpy, классификация фото по стилю.

Как именно AI встроен в систему тестирования
Это ключевая фишка проекта — не «два проекта рядом», а один пайплайн:

Пользователь проходит тест — в TestResult сохраняется PredictedStyleId (стиль, выведенный из ответов).

Пользователь загружает фото — C# вызывает Python‑сервис — получает style_id и confidence.

Результат AI сохраняется в отдельную таблицу StyleAnalysis.

TestResult ссылается на StyleAnalysis через внешний ключ и хранит флаг AiConfirmed:

AiConfirmed = (TestResult.PredictedStyleId == StyleAnalysis.PredictedStyleId).

То есть на уровне БД есть настоящая связь между «ответами теста» и «вердиктом нейросети». Расхождение — это не баг, а метрика: она показывает, насколько самооценка пользователя совпадает с объективным визуальным сигналом.

Визуальный стиль для фронта (не факт что он будет, если успею то постараюсь сделать)
Тёмная тема в серо‑фиолетово‑синей гамме:

Фон: #0E1020, панели: #161A2E, карточки: #1E2340.

Акценты: #7A6DF0 (фиолетовый), #3A8BEF (синий), #22D3EE (циан).

Градиенты 135deg на кнопках и заголовках, мягкие свечения box-shadow.

Карточка стиля показывает палитру из 4 цветов, одежду, хобби и направления обучения.

Что демонстрирует проект с технической стороны
REST API + контроллеры — AuthController, StyleController, TestsController, ManagerController.

EF Core + LINQ — AppDbContext, запросы с Include, Select, Where, OrderBy.

Связи в БД — User 1─* TestResult, TestResult 1─1 StyleAnalysis, каскадные удаления.

DI и lifetimes — AddDbContext (Scoped), AddSingleton<IJwtService>, AddHttpClient.

Асинхронность — все CRUD‑методы async Task<...> с CancellationToken.

Миграции — dotnet ef migrations add, database update при старте.

JWT + роли — [Authorize(Roles = "Manager")], claims с NameIdentifier и Role.

Хеширование пароля — BCrypt.Net.

Fluent Validation — валидаторы для RegisterDto, CreateTestDto, SubmitAnswersDto.

Unit‑тесты — xUnit + Moq + InMemory для сервисов, pytest для Python.

Микросервисы — Python‑сервис через HttpClient, health‑check, изоляция ML от бизнес‑логики.

ML с нуля — собственный датасет, признаки, MLP, backprop, Adam — без PyTorch и sklearn.

Ценность проекта
Практическая — реально работающий AI‑стилист с осмысленной связкой двух сигналов.

Техническая — покрывает весь стек современного backend‑разработчика: API, БД, авторизация, DI, тесты, микросервисы.

Исследовательская — показывает, как связать ML‑компонент с классической бизнес‑логикой через честную схему данных, а не через «приклеенный» скрипт.

Образовательная — сама нейросеть написана с нуля, что демонстрирует понимание математики (softmax + cross‑entropy, градиенты, Adam), а не умение вызывать model.fit().
